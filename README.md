# 劳动防护用品管理系统

Gitee 静态 H5 + Supabase 免费版，全程零成本。

## 技术栈

- **前端**：纯 HTML + CSS + JavaScript（无框架，适合 Gitee Pages 静态托管）
- **后端**：Supabase（PostgreSQL 数据库 + 自动 REST API）
- **手写签名**：Canvas 原生实现
- **二维码**：在线 API 生成（qrserver.com）

## 角色与入口

| 角色 | 页面 | 说明 |
|---|---|---|
| 管理员 | admin.html | 电脑端 Web 后台，用品/产线/账号/需求/库存/报表 |
| 线长 | line-leader.html | 手机端，需求/签收/库存/领用兜底/月报审核 |
| 班组长 | team-leader.html | 手机端，领用确认/月报签名 |
| 员工 | employee.html?line=xxx | 扫码进入，领用登记 |

## 部署步骤

### 第一步：创建 Supabase 项目

1. 访问 https://supabase.com 注册免费账号
2. 新建项目（New Project），选择免费套餐
3. 项目创建完成后，进入 **Project Settings → API**
4. 复制 **Project URL** 和 **anon public key**

### 第二步：初始化数据库

1. 进入 Supabase Dashboard → **SQL Editor**
2. 打开本项目 `sql/init.sql` 文件，复制全部内容
3. 粘贴到 SQL Editor，点击 **Run** 执行
4. 执行成功后，数据库表和初始数据（默认管理员、示例产线、示例用品）就建好了

### 第三步：配置前端

1. 打开 `js/config.js`
2. 将 `SUPABASE_URL` 改为你的 Project URL
3. 将 `SUPABASE_ANON_KEY` 改为你的 anon key
4. 保存

### 第四步：部署到 Gitee Pages

1. 在 Gitee（gitee.com）创建一个新仓库
2. 将本项目所有文件上传到仓库（保持目录结构）
3. 进入仓库 → **服务** → **Gitee Pages**
4. 选择部署分支（通常是 master/main），启动部署
5. 部署完成后会得到一个访问地址，如 `https://你的用户名.gitee.io/仓库名/`

### 第五步：获取员工领用二维码

1. 用管理员账号登录 `admin.html`
2. 进入 **产线/班组** 页面
3. 点击对应产线的 **查看二维码** 按钮
4. 下载高清二维码，打印张贴到产线物料点

## 注意事项

1. **个人主体合规**：系统不采集手机号、身份证、工号等敏感信息，员工仅填姓名，定位为现场领用登记工具。
2. **数据安全**：Supabase 数据库已启用 RLS，当前策略为内部工具全开放（二维码仅工厂内张贴）。如需更严格的权限控制，可在 Supabase 中调整 RLS 策略。
3. **签名图片**：手写签名以 base64 格式存储在数据库中，单张约 50-100KB，免费版 500MB 数据库足够使用。
4. **二维码**：使用 qrserver.com 在线 API 生成，如需离线可替换为本地 qrcode.js 库。
